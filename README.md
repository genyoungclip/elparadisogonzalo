# elparadisogonzalo defi Repository

## Project Overview

**elparadisogonzalo** is a Web3-integrated dApp and defi built for **multi blockchain chains**. It tracks smart contract events, supports decentralized storage, and interacts with wallets and APIs using:

- Node.js
- Web3.js
- GitHub CLI
- Google Cloud CLI
- elparadisogonzalo CI
- elparadisogonzalo.net CI
- Web3 wallets
- Blockchain syncing

Linked to the **Domain**: <https://elparadisogonzalo.net>
